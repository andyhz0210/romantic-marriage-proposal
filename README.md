
# 求婚网页制作工具

在浏览器中定制姓名、纪念日、求婚日期、情书、誓言、回忆照片和音乐，预览后导出可离线观看的成品。导出过程在本机浏览器完成，不需要生成服务或账号。

## 本地开发

使用 Node.js 22.12+ 或 Node.js 24：

```powershell
npm ci
npm run dev
```

打开 http://localhost:3000。启动前会自动生成离线展示模板。修改展示组件后，如需验证最新导出效果，执行 `npm run build:offline` 或重启开发服务。

## 制作与导出

1. 点击顶部“定制内容”，填写双方姓名、相恋纪念日、求婚日期和专属文案。
2. 在照片墙与誓言区域增删改内容。照片上传会保留比例，静态图片最长边缩至 1920 像素，并在有收益时使用 WebP 压缩；GIF 保留动画。单张图片最大 20 MB。
3. 可上传本地音乐（最大 30 MB），或输入音频 URL。照片墙模式、滚动速度和探照灯开关会随草稿保存。
4. 保存定制后，点击顶部“导出”，选择以下一种格式。

| 格式 | 使用方法 | 资源存放 |
| --- | --- | --- |
| 单文件 HTML | 在现代浏览器中直接打开下载的 HTML | 配置、照片、音乐、样式、交互和字体全部内嵌 |
| 离线项目包 ZIP | 完整解压，在浏览器中打开 `index.html` | 图片、音乐、字体、CSS 和 JS 存放在 `assets/`，使用相对路径 |

两种成品都无需 Node.js 或联网。ZIP 是成品网站包，不含 React 开发源码。正式成品隐藏编辑入口，保留照片查看、情书、誓言签收、戒盒、烟花、音乐与证书功能；每次打开从初始求婚状态开始。

原有四种字体已随成品携带，保持离线观感。因此，不含个人大素材的 HTML 也约有 9 MB，ZIP 约有 6 MB；添加照片和音乐后体积增加。字体许可证包含在 HTML 注释和 ZIP 的 `assets/fonts/LICENSE.txt` 中。

外部素材必须下载成功才能导出。链接的网络错误、超时或跨域限制会显示错误，不会默默省略素材。音乐链接无法打包时，可本地上传，或取消“打包背景歌曲”，改用内置音乐盒和音效。

## 草稿

内容和上传素材通过 IndexedDB 保存到当前浏览器，会自动迁移旧版 localStorage 草稿。存储失败会明确提示。不同浏览器、设备和域名的草稿不会自动同步；浏览器清理站点数据也会删除草稿。已导出的成品独立于草稿存储。

## 构建与验证

```powershell
npm run lint
npm test
npm run build
npm run preview
```

制作工具的正式产物在 `dist/`，可发布到静态托管平台。开发与构建都会先运行 `scripts/build-offline.mjs`，把共用的 `ProposalPage` 打包为无需外部模块的经典脚本与内嵌字体 CSS，生成 `src/generated/offline-runtime.json`。用户导出时填入配置与素材，而不在浏览器中编译源码。

导出测试验证 JSON 转义、单文件资源内嵌、ZIP 相对路径、素材去重、失败提示与取消操作。浏览器验证使用本机 Chrome 或 Edge，可指定 `PROPOSAL_BROWSER_PATH`，运行前先构建：

```powershell
npm run build
npm run test:browser
```

浏览器脚本验证本地文件在断网模式下的展示与交互、手机尺寸布局、草稿刷新保留，以及实际下载两种格式；截图、样例和结果写入 `artifacts/verification/`。

## 打开环境

音乐需要用户点击页面或播放按钮。剪贴板操作可能受到本地文件权限限制，提供替代复制和失败提示；打印只输出纪念证书。手机聊天软件的 HTML 附件预览可能不执行 JavaScript，请使用支持本地 HTML 的浏览器，或将成品发布到静态托管后通过网址观看。桌面浏览器与手机尺寸模拟通过验证，不等于已验证所有手机系统及聊天软件。
